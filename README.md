# 淘宝用户行为全链路分析

**500万条真实数据 · 漏斗诊断 · 用户分层 · 商品矩阵 · AI智能体落地**

[在线体验智能体](https://www.coze.cn/store/agent/7636038430912266303?bid=6judd66p05g14) | [查看完整报告](data_analysis/outputs/report.md)

## 这是什么项目
一个**数据分析 + AI 工程化**的全流程项目。从 SQL 随机从1亿条数据取500万条淘宝真实用户行为数据开始，到 Pandas 漏斗诊断、RFM 用户分层、商品矩阵分析，最终将分析能力封装为**可交互的 Coze 智能体**。

## 为什么值得看

- **漏斗分析**：发现加购与收藏信号价值趋同（转化率仅差 1.33%），挑战传统运营假设
- **用户分层**：t 检验验证分层有效性（p < 0.001），精准定位核心用户不足 1%
- **商品矩阵**：识别 6.2 万流量浪费商品 vs 8,853 个待挖掘潜力商品
- **AI 落地**：搭建双模式智能体，报告产出从 45 分钟压缩到 3 分钟
